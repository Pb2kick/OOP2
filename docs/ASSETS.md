## What the licenses mean for this repo

- **Using the art inside the released game is fine.** That counts as using the asset, not redistributing it.
- **Keep the git repo private.** A public repo would republish the raw sprite sheet, which counts as redistributing the asset. If the code is ever made public, the art files have to be removed from it, with only a note on where to download the pack.
